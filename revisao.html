Introduction to HTML

HTML represents the content and structure of a webpage

Understanding divs and other semantic HTML elements in HTML

Div

The div Element
Purpose: Acts as a generic, non-semantic container used to group other elements together.
Behavior: It carries no visual style or inherent meaning. Developers use it as a layout block to apply CSS styles (like background colors or Flexbox alignments) or to manipulate sections of the page using JavaScript.

Header

Represents introductory content at the top of a page or section. It typically holds site logos, titles, or main navigation links.


Nav

Embedded inside the header, it contains the main navigation menu links (e.g., Home, About, Docs).


Article

The primary content block on the left side, containing the core topic of the page.


Section

Defines a standalone, thematic group of content. It acts as a semantic container grouping the entire layout together.


Aside

Contains secondary content indirectly related to the main article. It is commonly used for sidebars, callout boxes, widgets, or extra links.


Footer

Defines the bottom section of a page or layout block. It usually holds copyright notices, contact info, or footer navigation links.
